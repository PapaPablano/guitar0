SoundFont comparison

Dev-only listening page for choosing the bundled guitar and bass banks (plan U4).

  1. Make the prepared files with node scripts/prepare-bank.ts into dev/local/prepared/ (guitar-clean.sf3, guitar-distortion.sf3, bass-finger.sf3, bass-picked.sf3), and put a tab in dev/local/.
  2. Run npm run dev and open http://localhost:5173/dev/soundfont-compare.html?tab=ozzy.gp (use the port Vite prints, and any tab name in dev/local/).
  3. Pick a start second, then switch between A and B. Both play the same passage at matched loudness, with the synth's effects off unless you switch them on.
